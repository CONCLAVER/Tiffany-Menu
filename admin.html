Для сохранения изменений нужен Personal Access Token от GitHub.

  1. Откройте github.com/settings/tokens
  2. Нажмите "Generate new token (classic)"
  3. Note: Tiffany Menu Admin
  4. Отметьте: repo
  5. Скопируйте токен
